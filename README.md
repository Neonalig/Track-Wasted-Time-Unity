# Track Wasted Time - Unity Package
While browsing Reddit, I came across a cool free plugin called [Time Waster](https://www.reddit.com/r/Unity3D/comments/1m19id2/comment/n3ge35y/?utm_source=share&utm_medium=web3x&utm_name=web3xcss&utm_term=1&utm_content=share_button). It tracks your compile and reload times, very handy! But I thought, why not make my own version that's a bit more advanced and also a fun challenge?

## 📦 Installation

### Via Package Manager (Recommended)
1. Open Unity Package Manager (`Window > Package Manager`)
2. Click the `+` button and select `Add package from git URL...`
3. Paste this URL: `https://github.com/GameDevBox/Track-Wasted-Time-Unity.git`
4. Click `Add`

### Manual Installation
- Download the repository and place it in your project's `Packages` folder

## ⚡ How To Use
- After installation, open the tool by going to `Window > Timer Wasted Stats`
- The tool will automatically start tracking compilation and domain reload times
- View detailed statistics, history, and optimization tips in the editor window

## 🌟 Features
- **Real-time Tracking**: Monitor compilation and domain reload times as they happen
- **Advanced Cause Detection**: Identify exactly what triggered each recompilation
- **Historical Analytics**: View trends and patterns in your development workflow
- **Performance Warnings**: Get notified when compile times exceed healthy thresholds
- **Optimization Tips**: Receive suggestions to improve your development speed
- **Persistent Storage**: All data is saved and persists beween Unity sessions
